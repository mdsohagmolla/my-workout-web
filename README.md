# 🏋️ FitLog - Workout Library

FitLog is a modern workout library web application where users can explore workouts, view workout details, create a personal workout plan, and save workouts for later.

## 🚀 Features

- 🏋️ Browse workouts
- 📖 View workout details
- 📋 Add workouts to My Plan
- 💾 Save workouts for later
- ❌ Remove workouts from Plan and Save
- 🚫 Prevent duplicate workouts
- ⭐ Workout ratings
- 🔥 Calories burned information
- ⏱️ Workout duration
- 💪 Muscle group information
- 📱 Responsive design
- 🌙 Modern dark UI

## 🛠️ Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Context API
